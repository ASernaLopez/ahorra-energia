¿Cómo funciona esta encuesta?

Este formulario utiliza el método GET de HTML5. Al enviarlo, el navegador incorpora los datos de la encuesta como parámetros en la dirección URL.

La actividad permite comprender cómo un formulario recopila y transmite información. Este ejemplo no almacena las respuestas en una base de datos.

Para realizar pruebas, utiliza datos de ejemplo y evita ingresar información personal sensible, porque las respuestas aparecen en la dirección del navegador.
